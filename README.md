# vibecar

3D car controller - physics-based driving with Three.js

Driving now follows the original 60 Hz simulation at any display refresh rate,
with bounded frame-gap recovery. See [release notes](RELEASE_NOTES.md) and the
[driving regression checks](tests/gameplay/README.md).
